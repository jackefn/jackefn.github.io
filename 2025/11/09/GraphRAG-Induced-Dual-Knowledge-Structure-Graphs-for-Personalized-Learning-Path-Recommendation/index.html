GraphRAG-Induced Dual Knowledge Structure Graphs for Personalized Learning Path Recommendation

原文链接：https://arxiv.org/pdf/2506.22303

Background & Motivation

本论文的Task为学习路径推荐（LPR），旨在为每个学生构建出符合特定教育目标的练习序列，学生通过作答这一系列顺序问题，能够掌握指定的目标知识点，既需要构建出知识点间的关系序列（学生需要先掌握哪个知识点，后掌握哪几个知识点，掌握这些内容后才能掌握目标知识点…），又需要根据学生的作答记录动态选择练习题目（比方说学生答错了一道较难的问题，那么接下来需要选择难度较低的问题）。

由此可知，知识概念（KC）的结构在学习路径推荐领域起着关键作用（需要根据知识概念的顺序来确定选题顺序）。现有结合KC结构的学习路径推荐方法分为两类：

  • 基于关联的方法：通过挖掘知识概念之间的隐形语义或统计关联推断个性化学习路径；

  • 基于先决条件的方法：利用线性先决条件关系指定学习个性化学习路径（建立KC图）。

目前，主要采用第二种方法。

然而，目前已有的数据集部分不存在已建立好的KC图，而已有图谱的数据集则存在概念缺失或依赖关系不准确的问题。想要构建出较好的KC图依赖于专家进行标注，需耗费大量的人工成本，而使用LLM生成KC图谱的方法因为缺乏关于知识概念的高质量文本描述，往往存在生成虚假关系的风险。此外，先决知识往往具有串联性，一个知识难以掌握，那么后续的知识也无法掌握，无法到达目标状态。因此，当学习者遇到学习障碍时，应该及时调整学习方向，例如更换一个相似的知识点来进行学习。（辨别学习）

基于上述挑战，本文贡献如下：

  • 提出EDU-GraphRAG模块，为不同数据集自适应生成知识概念的先决条件图和相似性关系图；
  • 引入DLRL模块，当先决条件失效时，引入相似性关系作为替代方案。

Methodology

1. 知识概念图生成

知识概念解释生成：借鉴TextGrad思路，首先让LLM为每个知识概念生成一份初始的分析报告（分析该概念与其他概念之间的联系），然后将该报告输入另一个LLM，对当前报告进行评估，并生成反馈意见，LLM根据反馈意见来重写分析报告，迭代T轮。

EDU-GraphRAG：将上述生成的知识概念-分析报告拼接成一个长文档，然后对其进行分块，提取每个块里面的实体和关系，构成若干个子图，再对子图进行合并，获得全局的图索引。该模块进行工作时，给定问题$Q$和图索引，输出$A_G$，即先决知识概念图和相似知识概念图。

2. 学习路径生成

知识追踪：采用DIMKT算法，通过学习者的历史练习记录的知识点以及练习题目的难度，动态预测学习者知识掌握程度，本论文将其作为RL的Environment。

先决知识概念Agent：在先决知识概念图的约束下，选择下一个需要学习的知识点。

  • 状态编码$s_t$：由学习者的历史知识状态$h_{t-1}$（每个知识点的掌握概率）和学习目标$G$（独热编码）构成，表示为：$1= h_{t-1} \oplus G$。

  • 策略：采取PPO优化策略，策略网络为$\pi(G|s_t;\theta)$，价值网络为$V(s_t;\phi)$，其中，策略网络在先决图谱的约束下输出每一个知识点的选择概率。价值网络采用MSE损失函数优化，策略网络优化形式为：

优势函数：

$1R_{et} + \cdots + \gamma^{T-t} V(s_T; \phi) \tag{11}$

损失函数：

$L(\theta) = \mathbb{E}_t\left[\min\left(r_t(\theta)\hat{A}_t, \text{clip}(r_t(\theta), 1-\epsilon, 1+\epsilon)\hat{A}_t\right)\right] \tag{12}$

其中，$r_t(\theta)$为新旧概率之比，clip为约束操作，$R_{et}$为最终步骤的奖励，可以表示为$1= E_p = \frac{E_{\text{end}} - E_{\text{start}}}{E_{\text{sup}} - E_{\text{start}}}$。$E_{\text{end}}$为路径推荐结束后学生对知识点的掌握程度，$E_{\text{start}}$为初始知识点掌握程度，$E_{\text{sup}}$为理论上的最大掌握程度。

相似知识概念Agent：根据相似知识概念图识别相似概念集合，筛选出能有效提升学习者掌握知识的子路径，架构与P-Agent一致。

难度Agent：确保当前选择练习题的难度与当前学习者掌握该知识概念的程度相符合，用于选择指定知识点的练习题。

学习路径构建机制：包括初始知识点选择以及Agent调用流程。

  • 初始知识概念选择：选择从初始节点出发，到达目标知识概念的最短路径。具体算法为：从目标节点出发，逆序进行遍历，若学习者已掌握当前知识概念，则终止遍历；若未掌握，则继续遍历至前置知识概念链最长的节点。
  • Agent转换机制：评估当前知识概念掌握的进步幅度$1= h_{t-1} - h_{t-2}$，若该幅度小于$\gamma$，则调用S-Agent选择相似的知识点进行学习，随后再替换为P-Agent。

Experiments

1. Datasets

三个教育资源数据集：Junyi、MOOCCubeX、ASSISTments2009，使用$E_p$来评估所有方法。

2. Main Results

如下表所示，在3个数据集均获得最优结果，并且可以观察到，其余方法随着推荐路径Step的增加，效果返回会出现下降，而本文的方法始终存在提升。

3. Ablation Study

主要是对S-Agent进行了消融研究，可以发现在去掉S-Agent后，随着Step的增高（尤其是15-20），会存在指标的下降，而加上S-Agent后，这种效果得到了明显的改善。

4. Knowledge Graph Visualization

对两个数据集自带的知识图谱和生成的图谱进行了可视化分析，发现生成的图谱知识概念更为全面，边也更多。

一些值得思考的点

  1. 本论文是通过llm生成概念文档，以此来充实概念节点之间的边的，感觉是一个不错的思路，某种意义上丰富了学习路径推荐的多样性，或许这也是为什么在Step 5时就已经超越了其余的方法，可见本文章构建的图较为有效。
  2. 文章中提出的S-Agent本质上是发现按图里原有的路径走知识掌握程度的幅度较小时，换一条路来走，可能提升幅度会变得更大，这也是S-Agent的意义。
  3. 按照本文的思路建好图以后，能不能建模为LLM驱动的Agent RL格式，把DIMKT模块作为环境，动态反应学生对知识点的掌握程度，能不能加上些教育的理论在路径选择这块讲些story。

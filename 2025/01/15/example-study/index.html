JavaScript 异步编程学习笔记

今天学习了 JavaScript 中的异步编程，记录一下学习心得。

Promise 基础

Promise 是 JavaScript 中处理异步操作的重要方式。它有三种状态：

  • pending（等待中）：初始状态
  • fulfilled（已完成）：操作成功完成
  • rejected（已拒绝）：操作失败
